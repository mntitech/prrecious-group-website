# PRRECIOUS GROUP Website — Phase 1

A premium black + gold responsive website prototype for PRRECIOUS GROUP.

## Included
- Home
- Services
- About
- Our Work
- Founders / Team
- Contact / Get a Free Quote
- Employee & Founder Portal UI
- Mobile responsive navigation
- Subtle logo animation only
- WhatsApp quote flow

## Important
The Employee Portal is currently only a front-end UI. Do not use it with real employee credentials yet.
The production version should connect authentication, database, project uploads, attendance and Admin Dashboard to a secure backend such as Firebase or Supabase.
